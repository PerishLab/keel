# Keel v0.10.3

## 声明的关系可以自带闭包

自引用的 many2many bond 现在可以声明 `closure`。derive 会在它旁边生成第二个关系,
名为 `<bond>_closure`,引擎让该关系始终等于直接联系的**非自反传递可达性**:

```rust
#[bond(many2many, target = "Part", closure)]
contains: Vec<Part>,
```

读 `contains` 得到直接持有哪些部件,读 `contains_closure` 得到任意深度可达哪些部件——
不需要递归查询,也不需要第二次往返。

该修饰符只对 many2many 有效。用在其他基数上是编译错误,与 `crew` 已有的拒绝在同一处。

## 闭包是被维护的,不是被重算的

每一条可能改变可达性的路径,都在改变直接联系的**同一个事务内**维护闭包:link、cut、
批量写入、schema 演进、查询读取,以及 operator Faces。回滚会把闭包一并带回,
所以读者不会看到与其来源联系不一致的可达性。

有两件事是拒绝而不是放任漂移。会形成环的联系被拒绝,因为环上的传递可达性没有非自反的答案。
对 `<bond>_closure` 关系的直接写入被拒绝为引擎所有,所以派生关系无法被改成与来源不一致。

## estate 格式十二

存储格式从十一升到十二。演进现在会在重塑 schema 的同一次迁移里刷新派生关系,
所以带有声明闭包的库演进完即是一致的,不需要额外一遍。
